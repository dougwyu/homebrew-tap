# dougwyu/tap

Homebrew casks for [dougwyu](https://github.com/dougwyu)'s macOS apps.

```bash
brew install --cask --no-quarantine dougwyu/tap/earthwallpaper
```

| Cask | App |
|---|---|
| `earthwallpaper` | [EarthWallpaper](https://github.com/dougwyu/EarthWallpaper): live Earth map desktop with day/night terminator and city clocks |
